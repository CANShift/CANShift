MOTION SPEC
Shift / rev limit — hard on-off at 6 Hz, no easing. Legibility beats smoothness.
Armed states — 1 s ease-in-out pulse between 100 % and 35 % opacity.
Critical alarm — whole screen pulses; the value never moves so it stays readable.
Value updates — snap, never tween. Tweened numbers lie about what the ECU said.
Bars and arcs — 120 ms linear catch-up, so they read as motion, not as jitter.
Stale data — value greyed and replaced by - - after 500 ms without a frame.
Page change — instant cut. No slide: the driver's eye must not track anything.
