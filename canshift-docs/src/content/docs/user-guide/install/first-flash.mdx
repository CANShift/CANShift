The flasher lives inside the tuner at `/firmware`. It's a 3-step wizard —
**Device** → **Firmware** → **Flash** — that reuses the active tuner
connection.

<TunerShell route="firmware" status="connected">
  <TunerFirmwareScreen activeStep={2} />
</TunerShell>

<Aside type="caution" title="Web Serial required">
  The flasher runs in a **Chromium-based** browser (Chrome, Edge, Brave, Arc,
  Opera). Firefox does not support Web Serial.
</Aside>

<Steps>

1. **Plug the screen** into your computer via USB-C.

2. **Open [Tuner → Firmware](https://canshift-tuner.vercel.app/firmware)** in a
   Chromium browser. The flasher lives inside the tuner — there is no separate
   flasher site any more.

3. **Pick the serial port** when the browser prompts. The screen shows up as
   "USB JTAG/serial debug unit" on most ESP32-WROOM boards.

4. **Choose a release** (latest stable by default).

5. **Click "Flash"** and wait ~30 seconds. The screen reboots itself at the
   end and shows the CANShift splash.

</Steps>

## Splash shows up but the bar stalls?

If the splash appears but the progress bar hangs, you most likely hit a heap
issue. See [Boot diagnostics](/user-guide/install/boot-issues/).

## No display after flash?

Check the TFT wiring — `MOSI=13`, `MISO=12`, `SCLK=14`, `CS=15`, `DC=2`,
`BL=27`. Full details on [Pinout](/technical/reference/pinout/).
