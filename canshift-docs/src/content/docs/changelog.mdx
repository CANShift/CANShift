<Aside type="note" title="Source">
Cette page reflète les **GitHub Releases** publiées sur [tburkhalterr/CANShift](https://github.com/tburkhalterr/CANShift/releases).
Chaque release décrit les changements visibles côté pilote, côté tuner, côté firmware,
et marque explicitement les breaking changes.
</Aside>

## Convention de rédaction

Chaque release suit cette structure :

```markdown
## [Version] — YYYY-MM-DD

### 🚗 Pour le pilote
- (UX, nouveaux widgets, support hardware, etc.)

### 🔧 Pour le tuner / l'installateur
- (config, calibration, paramètres ECU)

### 🔬 Firmware / Dev
- (build flags, schema, ports Rust, refactors)

### ⚠️ Breaking
- (impact concret + action requise — re-flash, re-burn config, etc.)

### PRs
- #XXXX — ...
- #YYYY — ...
```

Une release vide ou réduite à une liste brute de titres de PRs n'est pas acceptée :
le changelog public doit pouvoir être lu par quelqu'un qui n'a pas suivi le développement.
